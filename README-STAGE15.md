# GlossIRC 1.5 alpha

- IRC LIST channel browser (321/322/323), filter, sort and tap-to-join.
- Script editor Remote / Aliases / Popups / Variables tabs; variables view is read-only.
- mIRC foreground color palette insertion and formatting reset.
- Water bottle launcher icon (vector drawable).
- Right slide-out nickname drawer with per-nick menus.
- Explicit disconnect removes the session from active servers; saved profiles remain for reconnection.

Note: IRC LIST can be large; capped at 10,000 cached channels, 1,500 rendered matches. Some networks disable LIST. mIRC scripting remains partial. This source has not been compiled in this environment; use the included GitHub Actions workflow to verify.
